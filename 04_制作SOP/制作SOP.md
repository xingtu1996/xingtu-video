# 制作 SOP · AI 辅助流水线

> 单人可跑的 AI 视频生产流程（你是 AI 工程化专家，成本行业最低）

---

## 一、流程总览

```
选题 → 脚本 → 配音 → 画面 → 剪辑 → 双版导出 → 发布
 ①     ②      ③      ④      ⑤      ⑥        ⑦
```

## 二、各步骤详解

### ① 选题（5 分钟）
- 从 `00_选题库/` 选题，或从书稿/文章拆知识点
- 选题标准：1 个能落地 + 有反常识/痛点 + 可视觉化

### ② 脚本（20 分钟）
- 用 AI（Claude/豆包）按 `01_脚本/脚本模板.md` 生成初稿
- **你改 50%**：加个人表达、真实细节、去掉 AI 味（doubao-human-signal 可辅助）
- 产出：竖屏版 + 横屏版

### ③ 配音（10 分钟）
- 方案 A（低成本）：AI 配音（豆包/剪映配音），选自然男声
- 方案 B（人声）：自己录，AI 降噪（个人风格更强，推荐长期）
- 方案 C（数字人）：数字人分身（后期可选）

### ④ 画面（30 分钟）
- 竖屏：AI 生成封面/背景图 + 大字幕（剪映/CapCut）
- 横屏：屏幕录制真实操作（最有说服力）+ AI 生成图解
- 参考：AI 短剧成本已降至 400-1200 元/分钟，你的知识视频可更低

### ⑤ 剪辑（30 分钟）
- 剪映/CapCut 一键字幕 + 自动卡点 + 转场
- 人声 + 背景音乐（AI 生成 BGM）

### ⑥ 双版导出
- 横屏 16:9 主版 → 裁切竖屏 9:16 版
- 封面 3 张备选

### ⑦ 发布（10 分钟/平台）
- 竖屏：抖音、小红书（引流）
- 横屏：B站、视频号（深度）
- 标题 3 选 A/B，观察 CTR

## 三、节奏建议

- 初期：每周 2 条（验证形式）
- 稳定后：每周 3-5 条（AI 流水线可支撑）
- 每 10 条复盘：完播率/涨粉来源 → 调整选题

## 四、质量门禁（发布前）

- [ ] 前 3 秒有钩子
- [ ] 一个视频一个知识点
- [ ] 无公司敏感信息（脱敏扫描）
- [ ] 字幕无错别字（AI 生成字幕需校）
- [ ] 横竖屏双版齐全
